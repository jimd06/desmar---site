Πώς μπαίνει ο βοηθός στο site σας

Χρειάζεται να μπει μία γραμμή κώδικα στο site σας, μία φορά. Παίρνει περίπου 5 λεπτά και δεν χρειάζεται να είστε προγραμματιστής. Αν το site σας το φτιάχνει κάποιος συνεργάτης, απλά προωθήστε του αυτή τη σελίδα.

1. Αντιγράψτετη γραμμή κώδικα (παρακάτω ή στο email μας).
2. Επικολλήστεστο σημείο που δείχνουν οι οδηγίες της πλατφόρμας σας.
3. Ελέγξτεότι εμφανίζεται το κουμπί κάτω δεξιά.

Η γραμμή κώδικα

Αυτή είναι η δική σας γραμμή — αντιγράψτε την ακριβώς όπως είναι:

Αντιγράφηκε

Τη δική σας γραμμή κώδικα θα τη βρείτε στο email που σας στείλαμε. Μοιάζει έτσι (το xxxx είναι διαφορετικό για κάθε επιχείρηση):

<script src="https://api.desmar.ai/widget.js" data-client-id="xxxx" async></script>

Μία φορά, σε ένα σημείο. Ο κώδικας μπαίνει μία φορά για όλο το site — όχι σε κάθε σελίδα. Αν τον βάλετε κατά λάθος και σε δεύτερο σημείο, δεν χαλάει τίποτα: θα εμφανιστεί πάλι ένα κουμπί.

Οδηγίες ανά πλατφόρμα

Διαλέξτε σε τι είναι φτιαγμένο το site σας. Αν δεν το ξέρετε, ρωτήστε όποιον σας το έφτιαξε — ή στείλτε μας τη διεύθυνση του site και θα σας πούμε εμείς.

WordPress

Για sites σε δική σας φιλοξενία (WordPress.org). Στο WordPress.com χρειάζεται πληρωμένο πλάνο που επιτρέπει plugins· στο δωρεάν πλάνο δεν γίνεται.

  1. Μπείτε στη διαχείριση του site (συνήθως το-site-σας.gr/wp-admin).
  2. Πηγαίνετε Πρόσθετα → Προσθήκη νέου (Plugins → Add New), ψάξτε WPCode, πατήστε Εγκατάσταση και μετά Ενεργοποίηση. Είναι δωρεάν.
  3. Από το αριστερό μενού: Code Snippets → Header & Footer.
  4. Επικολλήστε τη γραμμή στο κουτί Footer (το τελευταίο από τα τρία).
  5. Πατήστε Save Changes.
  6. Αν έχετε plugin ταχύτητας (π.χ. WP Rocket, LiteSpeed Cache, W3 Total Cache), καθαρίστε την cache του — αλλιώς το κουμπί μπορεί να αργήσει να φανεί.

Αν το θέμα σας έχει ήδη δικό του πεδίο για κώδικα (π.χ. Divi → Theme Options → Integration, ή Elementor Pro → Custom Code), μπορείτε να τον βάλετε εκεί αντί για το WPCode — αρκεί σε ένα σημείο.

Wix

Χρειάζεται site δημοσιευμένο με δικό σας domain (όχι διεύθυνση τύπου wixsite.com).

  1. Στον πίνακα ελέγχου του site πατήστε Settings (Ρυθμίσεις).
  2. Στην ενότητα Development & integrations πατήστε Custom Code.
  3. Πάνω δεξιά: + Add Custom Code.
  4. Επικολλήστε τη γραμμή και δώστε ένα όνομα, π.χ. «Desmar».
  5. Στο Add Code to Pages διαλέξτε All pages και «Load code on each new page».
  6. Στο Place Code in διαλέξτε Body - end και πατήστε Apply.
Shopify
  1. Στη διαχείριση: Online Store → Themes.
  2. Δίπλα στο ενεργό θέμα πατήστε … και μετά Edit code.
  3. Αριστερά, στον φάκελο Layout, ανοίξτε το αρχείο theme.liquid.
  4. Βρείτε τη γραμμή </body> (συνήθως προς το τέλος) και επικολλήστε τη γραμμή κώδικα ακριβώς πριν από αυτήν.
  5. Πατήστε Save.

Αν αλλάξετε θέμα αργότερα, ο κώδικας πρέπει να μπει ξανά στο νέο θέμα.

Squarespace

Το site-wide Code Injection υπάρχει στα πλάνα Core, Plus, Advanced (και στα παλιότερα Business / Commerce)· όχι στο Basic.

  1. Αριστερά πατήστε Website και κατεβείτε στο Website Tools.
  2. Πατήστε Code Injection.
  3. Επικολλήστε τη γραμμή στο κουτί Footer.
  4. Αποθηκεύστε (Save) και ελέγξτε το δημοσιευμένο site — όχι τον επεξεργαστή.
Webflow

Χρειάζεται πληρωμένο site plan· ο κώδικας εμφανίζεται μόνο στο δημοσιευμένο site.

  1. Ανοίξτε τις ρυθμίσεις του site (Site settings) και την καρτέλα Custom code.
  2. Επικολλήστε τη γραμμή στο Footer code.
  3. Πατήστε Save changes και μετά Publish.
Joomla
  1. Πολλά θέματα Joomla έχουν στις ρυθμίσεις τους πεδίο για κώδικα: System → Site Template Styles → το θέμα σας → καρτέλα τύπου Custom Code, πεδίο για το τέλος της σελίδας (π.χ. «Body Custom Code» / «Before </body>»).
  2. Επικολλήστε τη γραμμή εκεί και αποθηκεύστε.
  3. Αν το θέμα σας δεν έχει τέτοιο πεδίο, μην πειράξετε τα αρχεία του θέματος μόνοι σας — ζητήστε το από όποιον σας έφτιαξε το site, ή από εμάς.
Hostinger Website Builder
  1. Στον builder ανοίξτε Website settings → Integrations.
  2. Επικολλήστε τη γραμμή στο πεδίο Custom code. Αν υπάρχει ήδη κώδικας εκεί, βάλτε τη δική μας γραμμή από κάτω — όχι μέσα στον άλλο κώδικα.
  3. Αποθηκεύστε και πατήστε Update website. Το κουμπί φαίνεται στην προεπισκόπηση ή στο δημοσιευμένο site, όχι μέσα στον επεξεργαστή.
GoDaddy Website Builder
  1. Ο GoDaddy Website Builder δεν έχει ένα σημείο για κώδικα σε όλο το site: ο κώδικας μπαίνει ανά σελίδα, με ενότητα HTML (Add Section → HTML → Custom Code).
  2. Επειδή έτσι ο βοηθός μπορεί να φορτώνει μέσα σε πλαίσιο της σελίδας και όχι κάτω δεξιά, επικοινωνήστε μαζί μας πριν το βάλετε — θα το δοκιμάσουμε μαζί.
Google Tag Manager

Αν το site σας έχει ήδη Google Tag Manager, αυτός είναι ο πιο εύκολος τρόπος.

  1. Στο Tag Manager: Tags → New.
  2. Tag Configuration: Custom HTML — επικολλήστε τη γραμμή κώδικα.
  3. Triggering: All Pages.
  4. Δώστε όνομα (π.χ. «Desmar»), πατήστε Save, μετά Submit και Publish. Χωρίς Publish δεν φτάνει στους επισκέπτες.
Άλλη πλατφόρμα ή site φτιαγμένο από προγραμματιστή
  1. Ο κώδικας μπαίνει στο κοινό πρότυπο όλων των σελίδων, ιδανικά ακριβώς πριν το </body>. Δουλεύει και μέσα στο <head>.
  2. Δεν χρειάζεται τίποτα άλλο: ούτε βιβλιοθήκες, ούτε cookies, ούτε αλλαγές στο CSS.
  3. Αν το site έχει Content Security Policy, επιτρέψτε το https://api.desmar.ai στα script-src και connect-src.

Στο Google Sites δεν γίνεται: δεν επιτρέπει κώδικα σε όλο το site. Επικοινωνήστε μαζί μας για εναλλακτική λύση.

Πώς ελέγχετε ότι μπήκε

  1. Ανοίξτε το site σας σε ανώνυμο παράθυρο (Ctrl+Shift+N στον Chrome) — έτσι δεν σας μπερδεύει η cache.
  2. Κάτω δεξιά πρέπει να δείτε ένα στρογγυλό κουμπί στο χρώμα της επιχείρησής σας.
  3. Πατήστε το και κάντε μια ερώτηση, π.χ. για το ωράριο. Δοκιμάστε το και από το κινητό.
  4. Αν δοκιμάσετε και ένα ραντεβού, θα σας έρθει email όπως σε κάθε πραγματικό αίτημα. Ακυρώστε το μετά από τη σελίδα διαχείρισης.

Δεν εμφανίζεται το κουμπί;

  1. Cache: καθαρίστε την cache του site (plugin ταχύτητας, Cloudflare ή φιλοξενίας) και ξαναδοκιμάστε σε ανώνυμο παράθυρο μετά από 1–2 λεπτά.
  2. «Καθυστέρηση JavaScript»: plugins όπως το WP Rocket (Delay JavaScript execution), το LiteSpeed Cache ή το NitroPack μπορεί να κρατούν τον κώδικα μέχρι να κουνηθεί το ποντίκι. Προσθέτετε το widget.js στις εξαιρέσεις τους (στο WP Rocket: File Optimization → Excluded JavaScript Files).
  3. Εργαλείο cookies: αν το εργαλείο συγκατάθεσης μπλοκάρει αυτόματα scripts (π.χ. Cookiebot, CookieYes), δηλώστε τον βοηθό ως λειτουργικό/απαραίτητο. Ο βοηθός δεν βάζει cookies διαφήμισης ούτε παρακολούθησης.
  4. Άλλη διεύθυνση: ο βοηθός δουλεύει μόνο στο domain που μας δηλώσατε (και στο www). Αν δοκιμάζετε σε δοκιμαστική διεύθυνση (π.χ. staging), πείτε μας τη να την προσθέσουμε.
  5. Ad blocker: δοκιμάστε με απενεργοποιημένο το ad blocker του browser σας.

Κόλλησε κάπου; Στείλτε μας τη διεύθυνση του site σας στο office@desmar.ai — το ελέγχουμε εμείς και σας λέμε τι ακριβώς να πατήσετε.

Ασφάλεια

  • Ο κώδικας φορτώνει μόνο τον βοηθό. Δεν διαβάζει τις φόρμες σας, δεν βλέπει κωδικούς ή πληρωμές και δεν αλλάζει τίποτα άλλο στη σελίδα.
  • Δεν επιβαρύνει την ταχύτητα: φορτώνει ασύγχρονα (async), αφού εμφανιστεί η σελίδα.
  • Η σελίδα διαχείρισης με τα ραντεβού σας ανοίγει μόνο με τον προσωπικό σας σύνδεσμο. Μην τον δημοσιεύετε.

Αν θέλετε να τον βγάλετε

Σβήνετε τη γραμμή κώδικα από το σημείο που την βάλατε (και καθαρίζετε την cache). Ο βοηθός εξαφανίζεται αμέσως, χωρίς να μείνει τίποτα στο site σας.
